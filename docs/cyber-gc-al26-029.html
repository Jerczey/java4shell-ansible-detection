Alert - AL26-029 - Critical vulnerability impacting Oracle Java - CVE-2026-114938

Number: AL26-029
Date: November 17, 2026

Audience

This Alert is intended for IT professionals and managers.

Purpose

An Alert is used to raise awareness of a recently identified cyber threat that may impact cyber information assets, and to provide additional detection and mitigation advice to recipients. The Canadian Centre for Cyber Security ("Cyber Centre") is also available to provide additional assistance regarding the content of this Alert to recipients as requested.

Details

The Canadian Centre for Cyber Security (Cyber Centre) is aware of a critical vulnerability affecting Java runtimesFootnote 1.

Tracked as CVE-2026-114938Footnote 2, this vulnerability is classified as a Heap-based Buffer Overflow [CWE-122]Footnote 3 that affects the Base64 standard Java library. Known as “Java4Shell”, the vulnerability could be exploited remotely without authentication by sending specially crafted base64 data to Java processes running on x86-64 processors that contain AVX-512 Vector Byte Manipulation Instructions (VBMI) hardware. Successful exploitation could result in memory corruption, disclosure of sensitive information, process crashes or arbitrary code execution in affected applications or services.

Oracle has released a security advisory addressing this vulnerabilityFootnote 4. Organizations should identify affected systems and apply applicable vendor updates as soon as they become available.

The Cyber Centre is not aware of active exploitation at this time, but that can change quickly.

Suggested actions

The Cyber Centre strongly recommends that organizations identify affected Java applications and update vulnerable components to an appropriate fixed release:

Affected Products Affected Versions Fixed Version
Oracle Java SE 8 8u511b33-perf 8u513-perf
Oracle Java SE 17 Versions 17.0.6 prior to or equal to 17.0.21.0.3 17.0.21.1
Oracle Java SE 21 Versions 21.0.13.0.3 and prior 21.0.13.1
Oracle Java SE 25 Versions 25.0.5.0.3 and prior 25.0.5.1
Oracle Java SE 27 Versions 27.0.1.0.3 and prior 27.0.1.1
Oracle GraalVM for JDK Versions 17.0.6 prior to or equal to 17.0.21.0.3 AND versions 21.0.0 prior to or equal to 21.0.13.0.3 17.0.21.1, 21.0.13.1
Oracle GraalVM Enterprise Edition Versions 21.3.20.0.3 and prior 21.3.20.1
Oracle OpenJDK Versions 17.0.6 prior to or equal to 27.0.1.0.3 27.0.1.1

For further details on affected versions and available fixed releases, please refer to the following Oracle advisoryFootnote 4.

The Cyber Centre recommends that organizations:

  • Inventory Java Environments. Audit all applications to identify active Java runtimes, including vendor, full build versionFootnote 5.
  • Update affected Java installations immediately to a fixed, supported release.
  • Prioritize Internet-facing systems and applications.
  • Identify third-party products, appliances and containers that include vulnerable Java componentsFootnote 6.
  • Where immediate remediation is not feasible, organisations should consider isolating internet-facing applications from public networks until a fix can be applied.
  • Consider disabling JVM support for AVX-512 by using JVM flag -XX:UseAVX=2 if you cannot patch.
  • To determine if your processor supports AVX-512, the following instructions can be used on Linux: lscpu | grep avx512.
  • Monitor for potential compromise by reviewing web server, application, authentication, and endpoint logs for suspicious activity.
  • Continuously monitor third-party vendors for security updates, including appliances, applications and services that bundle Java, and apply applicable patches without delay.

Organizations should also review the Cyber Centre’s Top 10 IT Security ActionsFootnote 7.

Should activity matching the content of this alert be discovered, recipients are encouraged to report via My Cyber Portal, or email contact@cyber.gc.ca.
